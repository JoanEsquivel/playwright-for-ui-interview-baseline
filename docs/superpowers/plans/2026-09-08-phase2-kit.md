# Phase 2 — Standards Kit (AGENTS.md, rules, skills, agent, hook) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Package the standards proven in Phase 1 as a portable, app-agnostic kit: `AGENTS.md`/`CLAUDE.md`, path-scoped rules, six skills (architecture, scaffold, create-test, fix-test, delete-test, ci), one `qa-engineer` agent, and a lint hook.

**Architecture:** `AGENTS.md` is the short always-on contract; `.claude/rules/*.md` add path-scoped detail; skills carry procedures plus templates (so a plugin extraction is a folder copy); the agent preloads `playwright-architecture` + `playwright-cli` and routes to the other skills. Every app-specific value is a parameter resolved from `.env`/`AGENTS.md` or asked for.

**Tech Stack:** Markdown with YAML frontmatter (Claude Code skill/agent/rule formats, also read by Copilot and Cursor), Node ESM script for scaffolding, bash hook.

**Spec:** `docs/superpowers/specs/2026-09-08-playwright-standards-kit-design.md` (Phase 2 section).

## Global Constraints

- No absolute paths, no app names, no URLs inside `.claude/skills/**`, `.claude/rules/**`, `.claude/agents/**` except as clearly labeled examples. Parameters: `BASE_URL`, `API_BASE_URL`, `E2E_USERNAME`, `E2E_PASSWORD`, `API_USERNAME`, `API_PASSWORD`, `LANGUAGE` (`ts` default | `js`), `PACKAGE_MANAGER` (`pnpm` default | `npm` | `yarn`).
- Size limits: `AGENTS.md` and `CLAUDE.md` < 200 lines; each rule file < 60 lines; SKILL.md bodies focused, details in `references/`.
- Skill frontmatter: `name` (equals folder name), `description` (what + when, trigger phrases), optional `allowed-tools`.
- Every skill ends with a verification step (`lint` + the relevant `playwright test` command) and a checklist.
- Commit per task with the session attribution trailer.
